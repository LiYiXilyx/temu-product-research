# 第一周字段字典

| 字段 | 类型 | 来源 | 备注 |
|---|---|---|---|
| 站点国家 / 币种 / 类目 | 文本 | 配置 | 第一周固定德国、EUR |
| Temu标题 / 主图 / 链接 | 文本 | 分类页与详情页 | 链接按goods_id规范化去重 |
| 单价 / 销量 / 评分 | 数值 | 结构化数据优先，页面文字兜底 | K/M销量会转成整数 |
| 近30天评价数 | 整数 | 原始评价表 | 含抓取日，共30个自然日，即不早于抓取日减29天 |
| 近30天日均评价数 | 数值 | 公式 | 近30天评价数÷30 |
| 差评推导 | 文本 | 1—3星评价 | 输出主题、数量和比例，可溯源 |
| 上架时间 | 日期 | 估算 | 当前已抓评价中的最早日期，不等于官方上架时间 |
| 是否入选 | 布尔 | 公式 | 价格、评分、日均评价及排除项全部通过 |
| 汇率 | 数值 | 配置 | 第一周默认8，可修改 |
| 寻源单价标准 | 数值 | 公式 | Temu欧元价×汇率÷5 |

电子/USB识别在第一周使用关键词规则，结果需要在正式决策前人工复核。
