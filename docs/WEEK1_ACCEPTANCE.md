# 第一周验收标准

## 功能验收

- 能用独立浏览器资料目录打开Temu分类页。
- 遇到登录或验证码时暂停并允许人工处理。
- 能按商品链接去重，目标试跑数量为100条。
- 商品与评价分别保存到SQLite，不把差评结论当作原始数据。
- 近30天评价统计使用可解析的评价日期。
- 差评结论带数量、比例，并能回查原始评价。
- 选品规则可在配置和Excel“字段说明”中查看。
- 能生成三张工作表的Excel结果。

## 数据质量验收

- 100条商品链接完整率应达到100%。
- 标题、价格、评分字段完整率目标不低于95%。
- 最近30天评价数需抽查至少10个商品，与页面人工计数对比。
- 对电子/USB识别结果抽查全部入选商品。
- 验证码、限流、选择器失效应写入错误记录，不静默丢失。

## 决策门槛

只有100条试跑通过字段完整率和评价抽查后，第二周才扩大到1000条。
